# 项目提案：音乐流派分类 (Music Genre Classification)

## 1. 项目概述
本项目旨在构建一个音频处理系统，能够读取音频文件（或实时录音），分析其声学特征，并将其分类为 10 种流派之一（如 Rock, Jazz, Blues, Classical 等）。

## 2. 技术路线
音频信号处理 + 深度学习分类。

### 核心技术
*   **特征提取**: 使用 `librosa` 库将音频转换为 **梅尔频谱图 (Mel Spectrogram)** 或 **MFCC (梅尔频率倒谱系数)**。将音频问题转化为图像分类问题。
*   **模型架构**: 卷积神经网络 (CNN) 或 长短期记忆网络 (LSTM)。CNN 在频谱图分类上表现极佳且更轻量。

## 3. PoC 与 MVP 规划

### PoC (Proof of Concept) - 概念验证 (1-2天)
*   **目标**: 验证数据处理流程和模型有效性。
*   **功能**:
    1.  加载 GTZAN 数据集，提取特征。
    2.  训练一个简单的 CNN 模型。
    3.  输入一个测试音频文件，输出流派预测。
*   **代码量**: ~200 行。

### MVP (Minimum Viable Product) - 最小可行性产品 (3-4天)
*   **目标**: 具备交互性的完整应用。
*   **功能**:
    1.  **交互界面/命令行**: 允许用户上传自己的 MP3 文件。
    2.  **可视化**: 展示音频的波形图和频谱图，并在旁边显示预测的流派概率条形图。
    3.  (可选) **实时功能**: 录制 30秒 麦克风音频并分类。
*   **代码量**: ~350-450 行。

## 4. 数据集与资源
*   **数据集**: **GTZAN Dataset** (最经典的音乐流派分类数据集)。
    *   **大小**: 约 1.2 GB。
    *   **内容**: 1000 个音频片段，每个 30秒，涵盖 10 个流派。
*   **来源**: Kaggle (https://www.kaggle.com/datasets/andradaolteanu/gtzan-dataset-music-genre-classification)

## 5. 硬件需求评估 (RTX 4060 8GB vs V100)

*   **结论**: **本地 RTX 4060 8GB 是“杀鸡用牛刀”，性能极大溢出，秒杀此任务。**

*   **分析**:
    *   **显存 (VRAM)**: GTZAN 数据集非常小，即使全部转换成频谱图图片，数据量也很小。模型也非常轻量（相比图像模型），8GB 显存可能只用到 1-2GB。
    *   **计算力**: 整个模型训练完成可能只需要 5-15 分钟。
    *   **注意**: 瓶颈通常在 CPU（用于 `librosa` 音频预处理），而不是 GPU。

## 6. 代码复杂度与可行性
*   **代码量**: 中等。需要学习 `librosa` 库的使用。
*   **创意分**: 中高。虽然是个经典任务，但如果加上酷炫的频谱可视化（Visualizer），演示效果会很好。
